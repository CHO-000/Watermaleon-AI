# Watermaleon-AI

ระบบจำแนกโรคจากภาพใบแตงโม 4 คลาสด้วย Deep Learning และ FastAPI สำหรับเชื่อมกับหน้าเว็บ

โค้ด API, น้ำหนักโมเดล, ผลทดสอบ และวิธีรันอยู่ใน [backend/README.md](backend/README.md)

ผลทดสอบบนภาพต้นฉบับที่แยกตามลำดับการถ่าย: accuracy **89.0%** (173 ภาพ) และ macro F1 **89.8%** ผลนี้ยังไม่ใช่การยืนยันความแม่นยำกับภาพจากสวนจริง
